# 🌴 Tropical Restaurante - Landing Page Institucional

Uma landing page moderna, elegante e totalmente responsiva desenvolvida para o **Tropical Restaurante**. O projeto destaca a gastronomia, a história da casa, o cardápio interativo, a apresentação do ambiente e facilita a realização de reservas e pedidos de delivery.

🌐 **Acesse a demonstração online:** [https://tropicalrestaurante.netlify.app/](https://tropicalrestaurante.netlify.app/)

---

## 📸 Visão Geral

O **Tropical Restaurante** combina uma estética acolhedora com recursos interativos focados na conversão de visitantes em clientes. O site conta com navegação fluida (*smooth scrolling*), destaques para promoções de boas-vindas, exibição de pratos recomendados pelo Chef e canais diretos para reservas de mesas via WhatsApp.

---

## ✨ Funcionalidades Principais

- **🎁 Banner & Modal de Oferta Especial:** Pop-up promocional que incentiva o cliente a realizar reservas pelo WhatsApp com cortesia do chef.
- **📱 Navegação Responsiva & Menu Mobile:** Menu hambúrguer adaptado para dispositivos móveis e navegação por âncoras rápidas.
- **📖 Cardápio Categorizado:** Apresentação visual das opções divididas em *Entradas*, *Pratos Principais*, *Sobremesas* e *Bebidas*.
- **👨‍🍳 O Chef Recomenda:** Destaques dos pratos mais pedidos da cozinha com fotos e descrições detalhadas.
- **🏡 Tour pelo Espaço:** Apresentação interativa das áreas do restaurante (salão climatizado, varanda ao ar livre, espaço familiar, área para eventos e estacionamento).
- **📅 Reservas & Delivery:** Seções estratégicas com chamadas para ação (CTA) para agendamento e pedidos online.
- **📍 Localização & Contato:** Informações claras sobre endereço, horários de funcionamento e canais de atendimento.
- **♿ Acessibilidade (a11y):** Estrutura desenvolvida com HTML5 semântico, atributos ARIA, rótulos descritivos e suporte à navegação via teclado.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação limpa e acessível (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3 Moderno:** Flexbox, CSS Grid, variáveis de estilo, animações suaves e design *Mobile First*.
- **JavaScript (Vanilla):** Interatividade para o menu mobile, modal promocional e navegação fluida.
- **Google Fonts:** Tipografia personalizada para reforçar a identidade visual da marca.
- **Netlify:** Plataforma utilizada para hospedagem e deploy contínuo.

## 🚀 Como Executar o Projeto Localmente

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/tropical-restaurante.git
   ```

2. **Navegar até a pasta do projeto:**
   ```bash
   cd tropical-restaurante
   ```

3. **Executar a aplicação:**
   - Abra o arquivo `index.html` em qualquer navegador.
   - Ou utilize a extensão **Live Server** no VS Code para rodar com *Live Reload*.

---

## ⚙️ Como Personalizar

Caso queira utilizar este projeto como modelo para outro estabelecimento:

1. **Cardápio e Pratos:** Edite os títulos, preços e imagens dentro das seções `#cardapio` e `#chef`.
2. **Links de Reservas:** Atualize os atributos `href` com o link direto do seu WhatsApp (`https://wa.me/55SEUNUMERO`).
3. **Informações de Contato:** Ajuste o endereço, telefone e horário de atendimento na seção `#localizacao` e no rodapé.
